# Security Policy

## Supported version

Security fixes are applied to the latest revision of the default branch.

## Reporting a vulnerability

If GitHub private vulnerability reporting is enabled, use the repository's **Report a vulnerability** button. Otherwise, open a minimal public issue asking the maintainer for a private contact channel; do not include exploit details, credentials, or personal data in that issue.

Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.
